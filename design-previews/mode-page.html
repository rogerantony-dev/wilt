How the ramp works

  • One colour per rung, not a continuous slider. Six fixed stops keep the values on the ladder and each stop has a name in the palette.
  • Everything selected takes the rung's colour: number, thumb, row border and tint, the Guilt radio, and the timer pill in the little preview. Nothing else on the page is coloured, so the shift is impossible to miss.
  • Passed rungs keep their own colour in the fill, so at 45 the track reads green, green, yellow, amber, orange under the thumb. The path there is visible.
  • Block stays green regardless. It sits at the safe end of the same scale, which is the argument for choosing it.
  • In React Native this is a plain View track with six Pressables and a colour picked from a six-entry table. No slider dependency, no gradient library, no native rebuild.
